01 // FUNDAMENTALS

DYNAMIC COMPARATOR

A dynamic comparator evaluates two analog input voltages and produces a corresponding digital output.

If $V_{IN+} > V_{IN-}$
$V_{OUT+} = 1, \quad V_{OUT-} = 0$

Unlike continuously biased op-amp comparators, it utilizes a clocked regenerative circuit.

Key Characteristics
  • Zero Static Power: Consumes power only during the evaluation clock edge.
  • Positive Feedback: Regenerative latch enables extreme high-speed resolution.
  • Applications: SAR ADCs, Flash ADCs, High-speed data converters, Memory sense amplifiers.

03 // TIMING & LOGIC

OPERATIONAL PHASES

PHASE 01: RESET
CLK = 0
  • Tail transistor is OFF (No path to ground).
  • Precharge PMOS transistors turn ON.
  • Internal nodes and outputs precharge:
$OUTP \rightarrow V_{DD} \quad|\quad OUTN \rightarrow V_{DD}$
PHASE 02: EVALUATION
CLK = 1
  • Tail transistor turns ON.
  • Differential pair discharges nodes at different rates based on $\Delta V_{IN}$.
  • Positive feedback amplifies the difference exponentially.
$OUT \rightarrow V_{DD} \quad|\quad OUT \rightarrow 0$

06 // PERFORMANCE CHARACTERIZATION

DELAY & POWER METRICS

PROPAGATION DELAY

Time measured from the CLK evaluation edge to a valid differential output.

TEST CONDITIONS ($\Delta V$)
1 mV 5 mV 10 mV 50 mV

Smaller input differences take exponentially longer to resolve.

ENERGY PER DECISION

Due to dynamic clocking, power is characterized as Energy per Comparison ($E_{comparison}$) rather than continuous static power.

$P_{avg} = V_{DD} \times I_{avg}$

$E_{comparison} = \frac{P_{avg}}{f_{CLK}}$
Example: P = 20 µW @ 100 MHz
E = 200 fJ / comparison
07 // NON-IDEALITIES

INPUT-REFERRED OFFSET

Ideally, the comparator switches at $V_{IN+} = V_{IN-}$. Transistor mismatch (threshold voltage, dimensions) creates an offset.

  • Offset is inversely proportional to $\sqrt{WL}$.
  • Requires Monte Carlo mismatch models to simulate accurately.
  • Critical metric for ADC resolution constraints.
