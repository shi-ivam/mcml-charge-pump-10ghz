ADE L RESULT COMMANDS — paste directly into Tools > Calculator
=============================================================

After the tb_mcml_charge_pump ADE L run has finished, open Tools > Calculator
and select Options > Algebraic Mode. For each numbered result, clear the
Calculator buffer, paste ONLY its single expression line, and click Evaluate.
These are Calculator expressions, not terminal commands or CIW load commands.
Nothing here imports a script or reruns the testbench. Each expression reads
the saved waveform results from the ADE run using an explicit resultsDir.

If CIW prints WARNING (OCN-6152) about ngspice-bridge, that warning is expected
for this setup. It says VT/IT shortcuts are unavailable; the expressions below
use OCEAN getData instead. A final "t" after "ViVA plotted..." means the
viewer script completed. Neither message is a measurement failure. Do not
paste the CIW transcript or its load("...il") command into a zsh terminal:
zsh will parse the quotes as shell syntax and can report "unmatched \"".
